# Purview Unified SDK

A modern Python SDK for Microsoft Purview Unified Catalog. Based on Microsoft Purview API Version 2026-03-20-preview

## Features

- Business Domains
- Data Products
- Data Assets
- Data Columns
- Glossary Terms
- Objectives
- Key Results
- Relationships
- Authentication
- Automatic pagination

## Installation

```bash
pip install purview-unified-sdk
